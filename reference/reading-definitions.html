Reading these definitions

How to read the part-English, part-math definitions in this course. Every name is either fixed or quantified, and the notation almost never says which. Worked all the way through on the fibre.

The through-line Each name in a definition plays one role: fixed (an input you supply), exists (Σ, a witness handed back), or for all (Π, a mapping you must provide). Which role a letter plays is a choice, not a property of the letter. The same letter can be fixed in one definition and quantified in another.

1. The three roles

In any definition, each name is playing one of these. The symbol tells you which, once you know the code:

how it appearsroleEnglish wordswhat it builds
free (given from outside)fixed / parameter"fix ___", "given ___", "for this particular ___"nothing, it is an input
λ(x:A). …abstracted (a fixed input, made explicit)"the rule that, given x, returns…"a function
Σ(x:A). …quantified, exists"there is some x", "a pair whose first part is x"a pair (x, …)
Π(x:A). …quantified, for-all"for every x", "for all x"a function x ↦ …

A free variable and a λ are the same idea (an input you supply); the λ just writes the "given" down explicitly instead of leaving it in the surrounding context. The real fork is input (fixed / λ) versus quantified (Σ exists, Π for-all).

2. The fibre, with no free variables

Here is the fibre of a function written as a fully closed definition. Every name is introduced by a binder, so nothing floats free:

Fibre  :=  λ (A : Type).
           λ (B : Type).
           λ (f : A → B).
           λ (b : B).
              Σ (a : A). (f a = b)

Fibre A B f b is what we elsewhere write fibre f b or fib_f(b). Read it aloud, naming every role:

In English, every role named Given a type A, given a type B, given a function f : A → B, given a point b : B: the fibre is the type of pairs (a, p) where there is some a : A and p proves f a = b. 
A : Type      FIXED   (λ-input)   "given a type A"
B : Type      FIXED   (λ-input)   "given a type B"
f : A → B     FIXED   (λ-input)   "given the function we study"   ← the subscript in fib_f
b : B         FIXED   (λ-input)   "given the base point"          ← the argument in parens
a : A         EXISTS  (Σ)         "there is some a"               ← the ONLY quantified name
p : f a = b   the proof carried alongside a inside the pair

Four "given"s and one "there is some." The notation hides all four "given"s. That missing English is what makes these definitions feel half-written.

3. Why a is "there is some" and not "for all" or "an input"

The fibre exists to collect the preimages of b. Its elements should be preimages, so each element must package one preimage with its proof. That package is a pair, so Σ.

  • Not Π: Π(a:A). (f a = b) reads "for every a, f a = b", i.e. "f is constant at b". A single, usually false claim about all of A, not a collection of preimages.
  • Not λ: λ(a:A). (f a = b) is the family of questions (A → Type), one per a. It waits for you to hand in an a. But the fibre hands as back; it does not demand one.

A concrete case where Σ and Π disagree, with f = id : Bool → Bool and b = true:

Σ (a : Bool). (a = true)   =   { (true, refl) }        inhabited: true lands on true   ✓ the fibre
Π (a : Bool). (a = true)   =   "true=true AND false=true"  =  empty: false ≠ true      ✗ not the fibre

Same f and b, opposite answers. Only Σ gives the fibre.

4. Why f and b are fixed, not special

f is fixed for one reason only: we chose to define "the fibre of a given function." Nothing about f forces this. You can quantify it like anything else, and get a different (legal) object:

Σ (f : A → B). Σ (a : A). (f a = b)     "there is some function f, and some a, with f a = b"
Π (f : A → B). …                          "for every function f, …"

f and b are peers: both are standing parameters you already hold. a is the one you go looking for. Nothing makes f special except the decision to hold it constant.

5. One Σ, three names

The fibre is not a special gadget. It is the ordinary dependent sum Σ(a:A). P(a) for one particular family:

let  P := λ(a:A). (f a = b)          -- P(a) = "the proofs that a lands on b"

Fibre A B f b  =  Σ (a : A). P(a)  =  Σ (a : A). (f a = b)

There is only ever one Σ, and it always means the same thing. It just wears three names, all describing the identical type:

namereadingwhere it is used
dependent pairthe type of pairs (a, y) with a:A, y:P(a)the mechanical definition
total spaceglue the fibre P(a) sitting over each point a into one space above Athe geometric picture
there exists (proof-relevant)"there is an a, and here is which one, with a proof of P(a)"the logical reading

These are not rivals to pick between. The pairs are the points of the total space, and the total space is the witnessed existence. A point upstairs needs to say which column it is in (a base point a) and which point in that column (y : P(a)), which is exactly the pair (a, y):

        P(a₁)      P(a₂)      P(a₃)
         •                     •
         •          •          •      ← each dot is a point  y : P(a)
   A ────a₁─────────a₂─────────a₃────  ← base points a : A

a point of the total space   =   a pair (a, y),  a:A, y:P(a)
Σ(a:A) P(a)                  =   collection of those pairs   =   the total space
fst : Σ(a:A)P(a) → A         =   send each dot down to its column a

"Total space" is just the name for the collection of pairs when you picture P as fibres stacked over a base. Drop the picture and it is a bag of pairs; add the picture and it is a bundle. Nothing changed but the drawing.

6. Why the fibre feels like a subset, not a bundle

It depends on what kind of family P is:

  • P(a) is a proposition (empty or one point): the stacks have height 0 or 1, so Σ(a:A) P(a) reads as "the as where P holds, each with its one proof" = filtering A to a subset.
  • P(a) is a general type (tall stacks): Σ(a:A) P(a) is a genuine bundle with real structure in each fibre.

The fibre's family is P(a) = (f a = b), an identity type. When A and B are sets, f a = b is a proposition (empty, or a single point), so the fibre collapses to "the preimages of b" and feels like a subset. In general it is a real space: if f a = b holds in several distinct ways (paths p ≠ q), the stack over that a is taller than one, and the fibre is a bundle, not a subset. Same Σ, same pairs; the family just got taller.

The caveat on "there exists." Σ is the proof-relevant exists: it hands back which a, not just the bare fact. The classical "there exists, do not tell me which" is the truncation ‖ Σ(a:A) P(a) ‖, which forgets the witness. So when a text reads Σ aloud as "there exists," it means the version that keeps the pair. That is why "collection of pairs" is the safe anchor and "there exists" is the lossy shorthand.

7. The pocket summary

fixed / λ   =  "given this"        an input you supply
Σ           =  "there is some"     a pair (witness + proof) handed back;  also "total space"
Π           =  "for all"           a mapping you must provide

Fibre A B f b  =  Σ (a:A). (f a = b)      with  P := λ(a:A). (f a = b)
   A, B, f, b : fixed (given)      a : exists (Σ)      p : the proof in the pair
   Σ(a:A) P(a) is one type with three names: pairs = total space = (proof-relevant) exists
Ask your teacher to read any other definition in the course this way: name each variable's role (fixed / Σ / Π), desugar it to a closed term, and say why each binder is the one it is. The fibre above is the template.
