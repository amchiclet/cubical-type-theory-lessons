ap, transport, J: one world

The same picture three times. A base space with a path, a bundle standing over it, and one move per operation. Only the bundle changes. A companion to Lesson 5.

The single frame Everywhere below: a base type A with two points a, b and a path p : a = b, and a bundle standing over A (a type sitting over each base point, projecting down by π). ap, transport, and J are three moves in this one world. The base and the path p never change. What changes is which bundle stands over the base, and what the path does to it.

0. The world

Read this once and hold it fixed. A base A at the bottom; a path p from a to b; over each base point a fibre (a type). The whole thing above the base is a total space; π projects it back down.

1. ap: slide the path, read the wake

ap f : (a = b) → (f a = f b). Here the bundle is the constant one: the same type B sits over every base point (a slab, not varying stalks). A function f : A → B picks one point of B over each base point. Slide along p and the chosen point traces a path in B: that wake is ap f p.

2. transport: lift the path, carry a point

transport P p : P a → P b. Now the bundle genuinely varies: the fibre P a over a and the fibre P b over b are different types. Take a point u : P a. The path p lifts horizontally to carry u across to a point of the neighbouring fibre P b.

3. J: the bundle that collapses

Now the bundle is special: the fibre over each point y is (a = y), the paths from a to y. This total space Σ(y:A)(a = y) is contractible, pinched to one centre (a, refl) over a. Our path p is just one point of it: the pair (b, p). To define anything over the whole bundle (a motive C), fill it at the centre; the collapse spreads it everywhere.

How they are secretly the same move

The diagrams are not just a family resemblance. Two exact facts glue them together.

transport is ap aimed at the universe A family P : A → Type is a function into the universe U. So ap P p : P a = P b is a path in U: a path between types. Then transport is "turn that path of types into a function" (coerce along it). In one line: transport P p = coerce (ap P p). Diagram 2 is diagram 1 run one floor up, in the space of types, then cashed in.

Drawn, it is literally diagram 1 with B replaced by the universe. The dots upstairs are now whole types, and the wake is a path between types:

ap and transport are both J Diagram 3 is the engine. Feed J the motive "P y" with centre value "u" and you get transport; feed it the motive "f a = f y" with centre value "refl" and you get ap f (this is the table in Lesson 5). Each of diagrams 1 and 2 is diagram 3 with the motive and the centre value filled in. The contraction to (a, refl) is what powers the wake in B and the lift across fibres alike.

So the whole page collapses to one sentence: a path in the base acts on whatever stands over the base, and J is the reason any such action is determined by its value at refl. ap is that action on a constant bundle, transport on a varying one, and reading P into the universe turns the first into the second.

Making it fully parallel: carry vs track

There is an asymmetry in the signatures that deserves to be faced head on. transport carries elements (P a → P b); ap hands back a path (f a = f b). Why the mismatch?

The reason is the dependence itself In the constant bundle, f a and f b live in the same type B, so they can be compared directly: the strongest thing to say is a path. In a varying bundle, u : P a and v : P b live in different types, so u = v is not even well-formed. "Same" cannot be stated. The only moves left are: go up to the universe (ap P p : P a = P b, a path between the types), or carry an element across and compare after arrival. transport is that carry.

So each world offers two operations: carry a bare element across the path, or track a function's images along it. That is a two-by-two square, and two of its corners we have not named yet:

carry a bare elementtrack a function's images
constant bundle Btransport (λ_. B) p : B → B: exists, but it is the identity (up to a path). Nothing varies, so carrying does nothing.ap f p : f a = f b: the wake. This is where the content lives.
varying bundle Ptransport P p : P a → P b: the lift. This is where the content lives.apd f p : transport P p (f a) = f b: the dependent ap, spelled out below.

The two named corners of Lesson 5 sit on the square's interesting diagonal. The boring corner (carrying over a constant bundle) is the identity, which is exactly why ap's output is the wake instead: with nothing happening in the carry, all the information is in how the section moves. And the fourth corner is a genuine, standard operation:

ap  : (f : A → B)         → (p : a = b) → f a = f b
apd : (f : (x:A) → P x)   → (p : a = b) → transport P p (f a) = f b
                                            └── carry first ──┘  └ then compare ┘

apd is ap for a dependent function (a section of the bundle). Its images f a : P a and f b : P b are in different fibres, so the naive conclusion f a = f b is ill-formed; the type of apd must use transport in its own statement to carry f a into P b before comparing. Drawn in the same world:

This same "carry first, then compare" shape is not new to you: it is the Σ-type row of Lesson 5's pattern table, ((a,u) = (b,v)) ≃ Σ(q : a = b). transport q u = v. Comparing second components of a dependent pair has to transport for exactly the reason apd does: until you carry, the comparison is ill-formed.

Stress test: swap the base for S¹

The frame claims to be one world, so it should survive changing the base. Replace A by the circle (Lesson 8): now a = b = base and the path is p = loop : base = base, a path that comes back. Run the same three moves.

ap over S¹: the wake is a loop

transport over S¹: the lift climbs (the helix)

J over S¹: the fan still collapses, and loop still isn't refl

One last echo: the stack (base, refl), (base, loop), (base, loop²), … sitting over base in the J picture is exactly the …, 0, 1, 2, … stalk in the transport picture. That is encode-decode drawn: the true fibre of paths and the Code fibre ℤ are the same ladder, and π₁(S¹) = ℤ is the statement that they match rung for rung.

Ask your teacher to push any diagram further: "draw ap P p as a path in the universe and then coerce it," "show the contraction of the fan by hand," or "what does the loop of S¹ do to each of these three pictures."
