Kan Operations and Glue

The interval gave paths contents. Two machines — transport and hcomp — make them move, and one type former — Glue — turns an equivalence into a real path. At the end of this lesson, univalence is a theorem that runs.

The win for this lesson You can name the two Kan operations and say what each does, explain how Glue builds the path ua e, and follow transport (λX.X) (ua not) true all the way to false — the exact term that jammed in Lesson 9, now reducing to a value.

What's still missing, precisely

Lesson 10 lets you write paths. But J's powers need more:

  • to move along a path (transport, the engine of every payoff), and
  • to compose paths (p ∙ q — two lambdas out of I don't concatenate by themselves), and
  • to build a universe path out of an equivalence (ua) — what type sits between Bool and Binary at time i?

Machine 1: transport, computed by the shape of the type

Cubical makes transport a program: it recurses on the type former of the path's fibres. Each type former says how to carry its own data:

transport over a pair type      = transport each component
transport over a function type  = transport the input backwards, the output forwards
transport over ℕ, Bool, …       = identity (nothing varies)
transport over a Glue type      = run the equivalence           ← the punchline, below

No axiom anywhere: transport unfolds, case by case, like any recursive function. (This structural unfolding is exactly the "identity mirrors structure" pattern from Lesson 5, turned into an algorithm.)

Machine 2: hcomp — composition is box-filling

How do you compose p : a = b with q : b = c? Draw the open box and ask for its lid:

        a ·············· c      ← the LID: the composite  p ∙ q  (what we want)
        │                │
   refl │                │ q       hcomp = "every open box has a lid."
        │                │         give it the three walls; it returns the lid,
        a ────── p ────── b        and the filling in between.

hcomp (homogeneous composition) is the primitive that fills such boxes, in any dimension. Path composition, associativity, inverses, and all the higher coherence of the Lesson 1 tower are instances of box-filling. Types equipped with transport + hcomp are called Kan types — "Kan" is the classical name for spaces where every open box can be filled — and in cubical, every type is Kan by construction.

Machine 3: Glue — the type between Bool and Binary

To define ua e : A = B we need a path in the universe: a function λ i → ?ᵢ with ?₀ ≡ A and ?₁ ≡ B. What is the type in the middle? Glue manufactures it: a type that is B, with A glued onto one face along the equivalence e:

ua e = λ i → Glue B [ (i = i0) ↦ (A, e) ,  (i = i1) ↦ (B, id) ]

        i0                    i1
        A ── glued along e ──▶ B        at i0 the Glue type is A (via e),
                                        at i1 it is just B — endpoints hold
                                        judgmentally, so this IS a path A = B.

And the computation rule for transporting over a Glue type is: go through the equivalence. That single rule is what was missing all course:

transport (λ X → X) (ua not) true
  = transport over a Glue type              -- unfold ua
  = not true                                 -- Glue's rule: run the equivalence
  = false                                    -- DONE. a value. no jam.
Univalence, upgraded from axiom to theorem With Glue, the map ua : (A ≃ B) → (A = B) is a definition, and one can prove it is inverse to idtoequiv — univalence becomes a theorem of the system. And canonicity is restored: every closed Bool computes to true or false again, univalence included (proved for this theory by Huber). The Lesson 9 disease is cured, not worked around.
Honesty flags. (1) The full reduction rules for hcomp and Glue are genuinely technical — this lesson is the faithful conceptual layer; the definitive source is the CCHM paper below. (2) The trade recorded in Lesson 5 stands: in cubical, J's own reduction on refl holds only up to a path, not judgmentally. Cubical buys "everything computes" at that small price.

Check yourself

Answer from memory first. The click gives immediate feedback.

What is hcomp, in one phrase?

Composition, inverses, and the higher coherence laws are all "give the walls, get the lid" — box-filling. Types with transport + hcomp are Kan types, and in cubical every type is one.

What does Glue contribute that the interval alone could not?

A universe path needs an actual type at each i. Glue B [(i=i0)↦(A,e), …] is that type — B with A glued along e — and its transport rule ("run the equivalence") is what makes ua compute.

Say it in your own words

A colleague asks: "so how exactly does cubical make univalence compute?" Answer in three sentences.

Cubical adds two Kan operations — transport, which is computed by recursion on the type former, and hcomp, which fills open boxes and gives path composition and all the higher coherences. For univalence it adds the Glue type former, which builds the type interpolating between A and B along an equivalence, so ua e = λi → Glue … is a genuine definition whose endpoints are A and B judgmentally. Transporting over a Glue type computes by running the equivalence, so transport (λX.X) (ua not) true reduces to false, univalence is a theorem rather than a postulate, and canonicity holds again.
